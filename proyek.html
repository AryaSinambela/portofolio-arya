Aplikasi Del-Laundry

Fokus: Object-Oriented Programming & File Persistence

Pengembangan sistem manajemen operasional laundry. Proyek ini dibangun menggunakan Java dengan mengimplementasikan konsep OOP secara menyeluruh dan memastikan data tersimpan dengan aman menggunakan metode *file persistence*.

Hotel Reservation System

Fokus: Multithreading & Concurrency Control

Sistem simulasi pemesanan kamar hotel berbasis Java. Proyek ini difokuskan pada penanganan pemesanan tamu yang terjadi secara bersamaan (*concurrent*) menggunakan *synchronized methods* dan *multithreading*.

Health-Tracking App Prototype

Fokus: UI/UX Design & User Journey Mapping

Merancang purwarupa (*prototype*) aplikasi untuk memantau catatan kesehatan anak. Prosesnya mencakup riset *user persona*, pemetaan perjalanan pengguna (*journey mapping*), dan pembuatan desain interaktif menggunakan Figma.
